# Estoque Fácil

## Sobre o projeto

O Estoque Fácil é um sistema de controle de estoque desenvolvido como MVP (Produto Mínimo Viável), com o objetivo de facilitar o acompanhamento da quantidade de produtos disponíveis.

## Problema identificado

O projeto surgiu a partir da identificação de divergências entre o estoque físico e o estoque registrado no sistema, ocasionando erros nos pedidos e cancelamentos de vendas.

## Objetivo

Facilitar o controle de entrada e saída de produtos, permitindo identificar itens com estoque baixo ou zerado por meio de alertas.

## Funcionalidades previstas

- Controle de entrada e saída de produtos.
- Consulta de produtos cadastrados.
- Identificação de estoque baixo ou zerado.
- Alertas para auxiliar o controle de estoque.

## Projeto acadêmico

Desenvolvido na disciplina de Projeto de Software, como parte das atividades práticas do curso de Análise e Desenvolvimento de Sistemas.
